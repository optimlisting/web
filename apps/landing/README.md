## Astro Landing Page For OptimListing

- Astro 5
- Tailwind v4.x.x

### 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `pnpm install`             | Installs dependencies                            |
| `pnpm dev:landing`         | Starts local dev server at `localhost:4321`      |
